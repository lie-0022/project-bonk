# 1. 게임 개요

## 1.1 엘리베이터 피치

**검나쎄짐**은 5분 내외의 짧은 라운드 안에서 무기 3슬롯과 패시브 12종을 조합해 폭발적으로 강해지는 쾌감을 주는 **3D
핵앤슬래시 뱀서라이크**다. 플레이어는 전사·거너·마법사 중 하나를 골라 자동 공격으로 끝없이 몰려오는 적을 베어내고,
레벨업마다 등장하는 카드로 자신만의 빌드를 완성한다. 세 개의 스테이지를 돌파하며 각기 다른 보스를 처치하고, 최종
누적 점수로 온라인 랭킹에 이름을 올린다.

**제목의 유래:** '검나쎄짐'은 무기 **검**과 '**겁나 세짐**'을 합친 언어유희다 — '가만히 서 있어도 무기가 알아서
강해진다'는 핵심 경험을 제목 한 단어로 압축했다.

**발표용 부제(축약):** 적을 죽일수록 강해지는 반자동 마물학살 로그라이크 뱀서 서바이벌 — 무기가 알아서 싸워주는 핸즈프리
검사가, 무빙만 잘했을 뿐인데 마왕성 보스를 칼퇴근시키는 1인 3역(검·총·마법) 만능 헌터로 각성하는 무한 회귀 액션.

**발표용 부제(전체):** *적을 죽일수록 강해지는 잔혹한 반자동 마물학살자 로그라이크 뱀서 서바이벌 레전드 슈퍼 게임 —
가만히 서 있어도 무기가 알아서 적을 베어버리는 핸즈프리 검사가, 무기가 알아서 싸워주니까 그냥 멋있게 서 있기만 했을
뿐인데 영웅이 되어버린 사기캐가 되어, 무빙만 잘했을 뿐인데 마왕성 보스를 칼퇴근시켜버린 평범한 헌터의 비정상 성장록을 쓰면서,
무기 슬롯 3개 다 채웠을 뿐인데 마왕성 던전을 솔로 클리어해버린 양심 없는 자동전투 빌더로 각성하고, 평범한 검사인 줄
알았는데 알고 보니 총잡이였고 사실은 마법사이기도 했던 정체불명 1인 3역 만능 헌터의 마물 토벌 일지를 남기면서,
살아남기만 하면 되는 줄 알았는데 살아남으면서 검나 쎄져야 하는 잔혹한 이중 과제를 부여받아, 죽기 직전까지 강해지지만
결국 죽고 마는 잔인한 로그라이크 뱀파이어 서바이벌 무한 회귀 액션 RPG의 무대 위에서, 적을 베면 벨수록 무기가
진화하고 무기가 진화할수록 더 많은 적이 몰려오는 무한 지옥 루프에 갇혀버린 절망적 로그라이크 일대기*

## 1.5 핵심 차별점 (USP)

  - 2D 뱀서라이크가 아닌 **완전 3D 핵앤슬래시** 무대 — 오빗 카메라·점프·대시·다단 점프로 입체적 회피와 위치 선정이
    가능하다.

  - **직업 = 무기 = 플레이 스타일**: 전사(근접 부채꼴)·거너(직선 관통)·마법사(광역 폭발)가 사거리·교전 방식·빌드
    방향을 근본적으로 다르게 만든다.

  - **등급 시스템**: 같은 카드라도 Legend 1회 선택이 Common 4회와 맞먹는 수치 점프를 준다 — '운'이
    빌드의 가속 페달이 된다.

  - **보스 중심 스테이지**: 무한 생존이 아니라 5웨이브 후 종족별 특화 보스를 처치해야 다음 스테이지로 — 명확한 목표와
    끝이 있다.

  - **온라인 누적 점수 랭킹**: 3스테이지 완주 점수를 Firebase 리더보드에 등록, 상위 10위와 경쟁한다.

## 1.6 코어 게임플레이 루프

플레이어가 반복 경험하는 핵심 사이클은 다음과 같다.

|             |                                             |                                  |
| ----------- | ------------------------------------------- | -------------------------------- |
| **단계**      | **행동**                                      | **보상 / 결과**                      |
| 1\. 직업 선택   | 전사·거너·마법사 + 해금된 맵 선택                        | 무기·플레이 스타일·시작 빌드 방향 결정           |
| 2\. 입장 / 생존 | 자동 공격으로 5웨이브의 적 처치, 이동·점프·대시로 회피            | XP 오브·골드·드롭 아이템 수집               |
| 3\. 빌드      | 레벨업 카드 3장 중 1택 (무기 강화 / 신규 무기 / 패시브), 상자 구매 | 무기·패시브 누적 강화, 등급에 따른 수치 점프       |
| 4\. 보스 처치   | 텔레그래프를 읽고 종족별 보스 패턴 회피·격파                   | 스테이지 게이트 개방, 다음 맵 해금 + 이속 아이템 확정 드롭 |
| 5\. 진행 / 완주 | Stage1→2→3 돌파 (Stage3는 2단 보스 아레나)           | 누적 점수 산출 → 온라인 랭킹 등록, 로컬 BEST 갱신 |

**루프 요약:** 직업 선택 → 스테이지 입장 → 자동공격 생존 → XP/골드 수집 → 레벨업·상자 빌드 → 보스 처치 → 다음
스테이지 → 3스테이지 클리어 → 누적 점수 + 온라인 랭킹 등록.

# 2. 게임 흐름 & 씬 구조

## 2.1 씬 흐름도

게임은 5개 씬으로 구성되며, GameManager의 단일 상태머신(Starting / Playing / Paused /
GameOver / Win)이 전환을 관장한다.

> [MainMenu] ──시작──▶ [CharacterSelect] (직업 + 맵 선택) ──확인──▶ [GamePlay]
>
> · 맵0 첫 입장 시: IntroCutscene(3문단 타이핑) ▶ 게임 시작
>
> · 스테이지 진행: 웨이브 ▶ 보스 ▶ 게이트 ── 사망 ──▶ [GameOver] (단일 런 결과)
>
> · 3스테이지 클리어 ──▶ [GameClear] (누적 점수 + BEST + 온라인 랭킹 등록)

## 2.2 씬별 역할

|                 |              |                                                    |
| --------------- | ------------ | -------------------------------------------------- |
| **씬**           | **역할**       | **핵심 요소**                                          |
| MainMenu        | 진입점·시작 메뉴    | 커서 표시, 시작 버튼 (BGM 후킹 예정)                           |
| CharacterSelect | 직업 + 맵 선택    | 2D Spine 캐릭터 프리뷰(3직업), 해금된 맵만 선택, 잠긴 맵 Locked 표시   |
| GamePlay        | 본 게임 — 모든 전투 | 웨이브·보스·게이트. 스테이지 전환은 이 씬 리로드 + SelectedMapIndex 교체 |
| GameOver        | 사망 결과        | 단일 런 통계, 재시작(런 리셋) / 메인. 누적 점수는 미표시(의도)            |
| GameClear       | 완주 결과        | 좌측 누적 점수·내역, 우측 온라인 랭킹, 닉네임 등록, 신기록 표시             |

**개발 편의:** Editor의 PlayModeStartScene 설정으로 ▶ 재생 시 항상 MainMenu에서 시작한다.

## 2.3 스테이지 전환 방식

스테이지마다 별도 씬을 만들지 않고, GamePlay 단일 씬을 리로드하면서 GameSession.SelectedMapIndex만
교체한다(0 = 슬라임 / 1 = 고블린 / 2 = 스켈레톤). 맵 데이터·스폰 영역·게이트 배선이 인덱스에 따라 활성화되며, 이
구조 덕분에 한 씬에서 Stage3의 2단 보스(재무장)까지 처리된다.

# 3. 플레이어 & 조작

## 3.1 이동 · 점프 · 대시

플레이어는 New Input System + CharacterController 기반으로 움직인다. 공격은 입력이 필요 없는 완전
자동이므로, 플레이어 조작의 핵심은 '위치 선정과 회피'다.

|        |                            |                                  |
| ------ | -------------------------- | -------------------------------- |
| **동작** | **사양**                     | **비고**                           |
| 이동     | 8방향, 베이스 이동속도 6.0          | MoveSpeed 패시브로 가속 (Lv당 +1.0)     |
| 점프     | 기본 점프 + 다단 점프              | ExtraJump 패시브로 공중 추가 점프 (Lv당 +1) |
| 대시     | 0.2초 무적 이동, 1.5초 쿨다운       | 보스 AOE·접촉 데미지 회피의 핵심. HUD에 쿨 표시  |
| 자동 공격  | BasicAttack / WeaponSystem | 주기적으로 가까운 적을 자동 타격 (입력 불필요)      |

## 3.2 카메라

3인칭 오빗 카메라가 마우스로 yaw/pitch를 회전한다. SphereCast로 벽 통과를 방지하고(카메라가 지형에 박히지
않도록 당겨짐), 커서는 상황에 따라 자동 잠금/해제된다. 선택한 직업에 맞춰 캐릭터 모델(Visual_Root)이
자동 전환된다.

## 3.3 키 매핑 (플레이용)

|               |                               |
| ------------- | ----------------------------- |
| **키**         | **동작**                        |
| W / A / S / D | 이동                            |
| Space         | 점프 (ExtraJump 패시브 보유 시 다단 점프) |
| Shift         | 대시 (0.2초 무적, 1.5초 쿨)          |

컴포넌트를 제거한다. 전체 디버그 키 매핑은 부록 A 참조.*

# 4. 직업 & 무기 시스템

## 4.1 3직업 = 3무기

직업 선택이 곧 무기 선택이며, 이는 사거리·교전 거리·빌드 방향을 근본적으로 결정한다. 각 무기는 매 런에서 강화되는 독립
시스템이다.

|         |            |             |                                              |
| ------- | ---------- | ----------- | -------------------------------------------- |
| **직업**  | **무기**     | **패턴**      | **특징 / 빌드 방향**                               |
| **전사**  | 검 (Sword)  | 주변 부채꼴 베기   | 근거리 광역. 마일스톤마다 각도 확장 (180°→360°). 다단·연속 휘두르기 |
| **거너**  | 총 (Gun)    | 고속 직선 투사체   | 원거리 단일 표적. 마일스톤마다 관통 증가 (0→무한). 정확한 위치 선정 요구 |
| **마법사** | 마법 (Magic) | 느린 투사체 + 폭발 | 원거리 광역. 마일스톤마다 폭발 반경 확장 (2m→7m). 군집 처리에 강함   |

**무기 기본 스탯** (Lv1, 등급·패시브 적용 전). 각 무기는 쿨다운이 0이고 사거리 내에 적이 있을 때 자동 발동한다.

|            |         |           |              |                |
| ---------- | ------- | --------- | ------------ | -------------- |
| **무기**     | **데미지** | **발동 간격** | **사거리 / 반경** | **투사체**        |
| 검 (Sword)  | 20      | 1.5s      | 반경 3 (부채꼴)   | — (근접)         |
| 총 (Gun)    | 20      | 0.8s      | 사거리 15       | 탄속 20          |
| 마법 (Magic) | 30      | 1.5s      | 사거리 12 (+폭발) | 탄속 8           |

## 4.2 무기 슬롯 규칙

  - **최대 3슬롯**. 가득 차면 신규 무기 카드가 더 이상 등장하지 않고 강화 카드만 나온다.

  - **자동 발동**. 각 슬롯이 독립 타이머로 동작하며, 인터벌은 무기 데이터 + 공격속도 패시브로 결정된다.

  - **무기당 최대 Lv 15**. 동일 무기 카드를 재선택하면 +1.

  - **3슬롯 모두 채워지고 전부 Lv 15**에 도달하면 무기 카드는 등장하지 않고 패시브 카드만 나온다.

**데이터 구조:** 무기 스탯은 ScriptableObject(WeaponDataSO)로 관리되어 데미지·쿨다운·마일스톤
테이블을 데이터 주도로 조정할 수 있다 (Weapon_Sword_Data / Weapon_Gun_Data /
Weapon_Magic_Data .asset).

## 4.3 무기 강화 (레벨업 시 변화)

|                      |                          |
| -------------------- | ------------------------ |
| **변화 항목**            | **적용 방식**                |
| **데미지**              | 매 레벨 등급별 가중치만큼 누적 증가     |
| **공격 인터벌**           | 매 레벨 등급별 가중치만큼 단축        |
| **범위(각도/사거리/폭발 반경)** | 마일스톤(Lv 1·5·10·15)에서만 점프 |
| **관통 (총 전용)**        | 마일스톤에서 0 → 1 → 2 → 무한    |

## 4.4 무기 마일스톤 테이블

범위·관통 같은 '체감 큰' 성장은 매 레벨이 아니라 마일스톤(Lv 1·5·10·15)에서 점프한다. 이로써 성장 곡선에 또렷한
변곡점이 생긴다.

|             |          |          |           |           |
| ----------- | -------- | -------- | --------- | --------- |
| **무기 — 항목** | **Lv 1** | **Lv 5** | **Lv 10** | **Lv 15** |
| 검 — 부채꼴 각도  | 180°     | 240°     | 300°      | **360°**  |
| 검 — 반경 배율   | ×1.0     | ×1.4     | ×1.8      | **×2.5**  |
| 총 — 사거리 배율  | ×1.0     | ×1.3     | ×1.6      | **×2.0**  |
| 총 — 관통 수    | 0        | 1        | 2         | **무한**    |
| 마법 — 사거리 배율 | ×1.0     | ×1.17    | ×1.33     | **×1.67** |
| 마법 — 폭발 반경  | 2.0m     | 3.0m     | 4.5m      | **7.0m**  |

데미지·발동간격 성장은 마일스톤이 아니라 **매 레벨업 등급 카드**로 곱연산 누적된다. Lv15까지 풀 강화 시 데미지 최대 약
+1250%, 발동간격 약 −622%에 이른다 (6장 등급 효과 참조).

# 5. 패시브 빌드 시스템 (12종)

패시브는 레벨업 카드에서 무기와 함께 등장한다. 각 패시브는 최대 Lv 15(선택 횟수 기준)이며, 12종이
생존·공격·투사체·이동·메타 5계열로 나뉜다. 아래 표의 'Lv15 누적'은 모두
Common 등급으로만 15회 선택했을 때의 값이며, 상위 등급으로 선택하면 더 적은 횟수로 같은 수치에 도달한다(6장 참조).

## 5.1 생존 계열 (3종)

|           |                    |                  |                      |
| --------- | ------------------ | ---------------- | -------------------- |
| **패시브**   | **효과**             | **Lv1 (Common)** | **Lv15 누적 (Common)** |
| **최대 체력** | MaxHp +15 / Lv     | \+15 HP          | \+225 HP             |
| **HP 회복** | 초당 자동 회복           | \+0.5 /s         | \+7.5 /s             |
| **회피**    | 데미지 무효화 확률 (캡 60%) | 8.0%             | 70.6% → 캡 60%        |

## 5.2 공격 계열 (4종)

|            |                                             |                  |                      |
| ---------- | ------------------------------------------- | ---------------- | -------------------- |
| **패시브**    | **효과**                                      | **Lv1 (Common)** | **Lv15 누적 (Common)** |
| **공격 속도**  | 인터벌 ×0.95^Lv (floor 0.30), 발사체·검 모션 속도 동시 ↑ | ×0.95            | ×0.46 (2.17배 빨라짐)    |
| **치명타 확률** | **기본 5% + 0.5% / Lv 선형 가산** (캡 75%)         | 5.5%             | 12.5%                |
| **치명타 피해** | 기본 배율 1.5, +0.15 / Lv                       | 1.65× (+15%)     | 3.75× (+225%)        |
| **생명 흡수**  | 데미지의 N%를 HP로 회복 (캡 25%)                     | \+2%             | \+25% (캡)            |

*설계 메모 1: '발사체 속도'는 독립 패시브가 아니라 공격 속도의 파생 효과로 통합했다. 공격 속도가 빨라지면 발사체 이동 속도와
검 휘두르기 속도가 함께 빨라진다 — 스탯 수를 줄여 선택의 명료함을 높인 결정.*

*설계 메모 2 (v1.4): 치명타 확률은 점감 공식에서 **선형 가산**으로 변경했다. 패시브가 없어도 기본 5%가 항상 적용되어
모든 빌드가 치명타의 손맛을 보고, 레벨당 +0.5%(등급 가중치 적용 시 그 배수)로 예측 가능하게 성장한다. 상위 등급
카드(Legend ×4.0)로 선택하면 1회에 +2.0%씩 점프한다.*

## 5.3 투사체 계열 (1종)

|           |                                                    |         |          |
| --------- | -------------------------------------------------- | ------- | -------- |
| **패시브**   | **효과**                                             | **Lv1** | **Lv15** |
| **투사체 수** | 투사체 수 = 1 + floor(Lv/3) (총·마법 = 발사 수, 검 = 연속 휘두르기) | 1발      | 6발       |

## 5.4 이동 계열 (2종)

|           |                            |             |                      |
| --------- | -------------------------- | ----------- | -------------------- |

| **추가 점프** | 공중 추가 점프 +1 / Lv           | \+1 (더블 점프) | \+15                 |

## 5.5 메타 계열 (2종)

|         |                                    |                     |                     |
| ------- | ---------------------------------- | ------------------- | ------------------- |
| **패시브** | **효과**                             | **Lv1**             | **Lv15**            |

| **난이도** | 적 스폰 +15% / Lv, XP·골드 보상 +20% / Lv | 스폰 ×1.15 / 보상 ×1.20 | 스폰 ×3.25 / 보상 ×4.00 |

**메타 패시브의 묘미:** 「난이도」는 위험과 보상을 동시에 키우는 고위험·고수익 카드다. 적을 더 많이·강하게 만드는 대신
XP·골드 획득을 크게 늘려 빌드 가속과 점수를 밀어 올린다. 「행운」과 조합하면 폭발적인 스노볼이 가능하다.

## 5.6 점감 공식 & 캡 (Diminishing Returns)

무한 누적으로 인한 밸런스 붕괴를 막기 위해 확률형 스탯은 점감 공식 또는 선형+캡을 적용한다.

|        |                |                                  |
| ------ | -------------- | -------------------------------- |
| **스탯** | **캡**          | **비고**                           |
| 회피     | 60%            | 점감 공식 적용, 표기 누적값이 캡을 넘어도 60%로 수렴 |
| 치명타 확률 | 75%            | **선형 가산 (기본 5% + 0.5%/effLv)** — v1.4에서 점감 폐기 |
| 행운     | 80%            | 고등급 재분배 비중의 상한                   |
| 공격 속도  | 인터벌 floor 0.30 | ×0.95^Lv 지수 감소, 최소 인터벌 보장        |
| 생명 흡수  | 25%            | 흡수율 상한                           |

# 6. 등급 시스템

레벨업 카드는 등장할 때마다 등급이 무작위로 결정된다. 핵심 원칙: 레벨은 항상 +1이지만, 등급은 1회 선택의 '수치 폭'만
차등한다. 즉 Legend 카드를 뽑으면 같은 +1이라도 훨씬 큰 점프를 얻는다 — 이것이 디자인 기둥 ①(즉각적 성장
쾌감)과 ②(빌드 다양성)의 핵심 엔진이다.

## 6.1 등급 종류 & 등장 확률

등급 명칭은 코드 enum 기준이다: **Common · Epic · Unique · Legend**. 카드가 등장할 때마다
무작위로 결정되며, 기본 확률(행운 0 기준)은 다음과 같다.

|            |        |                  |
| ---------- | ------ | ---------------- |
| **등급**     | **색상** | **기본 확률 (행운 0)** |
| **Common** | 회색     | 60%              |
| **Epic**   | 보라     | 25%              |
| **Unique** | 노랑     | 12%              |
| **Legend** | 빨강     | 3%               |

**행운(Luck) 패시브**를 누적하면 Common 비중이 줄고 상위 등급 비중이 재분배되어 증가한다(가중치 샘플링, 캡
80%). CardGradeRoller가 이 확률을 계산한다.

## 6.2 무기 등급별 효과 (1회 선택의 수치 폭)

|            |              |                |
| ---------- | ------------ | -------------- |
| **등급**     | **데미지 +보너스** | **공격 인터벌 −단축** |
| **Common** | \+12%        | −6%            |
| **Epic**   | \+20%        | −10%           |
| **Unique** | \+32%        | −15%           |
| **Legend** | \+50%        | −22%           |

매 레벨업마다 누적된다. 예: **Legend 5회 선택 = 데미지 +250%.**

## 6.3 패시브 등급별 효과 (effective level)

패시브는 '레벨은 항상 +1'이되, 수치 환산용 effective level(유효 레벨)에 등급별 가중치가 누적된다. 같은 한
번의 선택이라도 등급이 높으면 유효 레벨이 더 크게 올라 더 큰 수치를 즉시 얻는다.

|            |                         |                                    |
| ---------- | ----------------------- | ---------------------------------- |
| **등급**     | **effective level 가중치** | **예: HpRegen 1회 선택**               |
| **Common** | ×1.0                    | effLv 1.0 → +0.5 HP/s              |
| **Epic**   | ×1.5                    | effLv 1.5 → +0.75 HP/s             |
| **Unique** | ×2.5                    | effLv 2.5 → +1.25 HP/s             |
| **Legend** | ×4.0                    | effLv 4.0 → +2.0 HP/s (Common 4회분) |

## 6.4 동작 사례 — 등급 혼합 누적

HpRegen 패시브를 등급이 모두 다르게 4회 선택한 경우, 유효 레벨이 합산되어 수치가 산출된다.

> Common 1회 → effLv 1.0 → +0.5 HP/s
>
> Epic 1회 → effLv +2.5 (누적) → +1.25 HP/s
>
> Unique 1회 → effLv +5.0 (누적) → +2.5 HP/s
>
> Legend 1회 → effLv +9.0 (누적) → +4.5 HP/s
>
> **→ picks = 4 (Lv15 캡 판정용), effLv = 9.0 (수치 산출용)**

**핵심 구분:** 선택 횟수(picks)는 Lv 15 상한 판정에 쓰이고, 유효 레벨(effLv)은 실제 수치 산출에 쓰인다.
두 값이 분리되어 있어 'Legend 한 방으로 빠르게 강해지되, 상한은 공정하게' 유지된다.

# 7. 진행 시스템 (XP · 골드 · 레벨업)

## 7.1 XP & 레벨업 곡선

적을 처치하면 XP 오브가 드롭되고, 수집하면 XP가 쌓여 레벨업한다. 레벨업이 빌드 성장의 주 동력이다.

|             |                                                   |
| ----------- | ------------------------------------------------- |
| **항목**      | **값 / 공식**                                        |
| **XP 획득**   | 적 처치 → XP 오브 드롭 → 수집 시 적립 (자석 아이템 시 즉시 흡수)        |
| **레벨업 요구치** | 100 + (Lv − 1) × 50 (Lv2=100, Lv3=150, Lv4=200 …) |
| **레벨업 효과**  | 전투 일시정지(timeScale=0) → 카드 3장 제시 → 1택 → 즉시 적용      |

## 7.2 골드

|           |                                           |
| --------- | ----------------------------------------- |
| **항목**    | **값 / 공식**                                |
| **골드 획득** | 일반 적 5 / 정예(러셔) 10 / **보스 200** (난이도·보상 배율 곱) |
| **상자 비용** | floor(50 × 1.5ⁿ) — 열수록 비싸짐 (n = 누적 구매 횟수) |
| **용도**    | 상자(Chest) 열기 → 레벨업 카드 선택 1회 (빌드 가속)       |

## 7.3 레벨업 카드 선택 흐름

레벨업(XPSystem.OnLevelUp) 또는 상자 구매가 트리거가 된다. 동작 순서는 다음과 같다.

|        |                                                       |
| ------ | ----------------------------------------------------- |
| **#** | **단계**                                                |
| 1      | Time.timeScale = 0 — 전투 완전 정지                         |
| 2      | 무기 + 패시브 풀에서 카드 3장 무작위 빌드 (각 카드에 등급 추첨)               |
| 3      | UI 표시 — 카드 3장 + 리롤/스킵 옵션                              |
| 4      | 플레이어가 1/2/3 키 또는 클릭으로 1택                              |
| 5      | 무기 카드 → WeaponSystem.AddWeapon / UpgradeWeapon 호출     |
| 6      | 패시브 카드 → PlayerStats.IncrementPassive(type, grade) 호출 |
| 7      | Time.timeScale = 1 — 전투 재개 (연속 레벨업은 큐잉)               |

## 7.4 카드 풀 규칙

|                     |                            |
| ------------------- | -------------------------- |
| **조건**              | **등장 카드**                  |
| 미보유 무기 + 슬롯 여유      | 신규 무기 카드                   |
| 보유 무기 + Lv 15 미만    | 무기 강화 카드                   |
| 미보유 또는 Lv 15 미만 패시브 | 신규 또는 패시브 강화 카드            |
| **모든 항목이 최대치**      | 카드 0장 → 즉시 재개 (낭비된 레벨업 방지) |

**리롤 / 스킵:** 플레이어는 제시된 3장이 마음에 들지 않으면 리롤(다시 뽑기)하거나 스킵할 수 있어, 빌드 방향에 대한
통제권을 일부 가진다.

# 8. 적 & 보스 디자인

## 8.1 잡몹 (Chaser)

잡몹(ChaserAI)은 플레이어를 추적하며 접촉 데미지를 준다. 오브젝트 풀링(IPoolable)으로 대량 스폰의 성능을
확보한다. 슬라임 계열은 '점프 내려치기' 옵션을 가져 단조로움을 깬다. 웨이브가 진행될수록 스폰 간격이 짧아지고
HP·이동속도가 상승한다.

## 8.2 보스 3종 & 종족별 패턴

각 스테이지는 종족이 다른 보스로 마무리되며, 보스마다 이동 방식과 공격 패턴이 뚜렷이 차별화된다 — 죽음의 원인을 즉시 학습할
수 있게 설계했다(디자인 기둥 ④). 등장 순서는 Stage1 슬라임 왕(SLIME KING) → Stage2 고블린
왕(GOBLIN KING) → Stage3 본 로드(BONE LORD, 스켈레톤)이며, 보스 HP는 각 1000이다.

|                    |        |                      |                                                              |
| ------------------ | ------ | -------------------- | ------------------------------------------------------------ |
| **보스 · 스테이지**      | **HP** | **이동**               | **주요 패턴**                                                    |
| **슬라임 왕 · Stage1** | 1000   | 점프로만 이동 (저속 추적 + 도약) | 도약 착지 내려치기 AOE (착지점 원형 예고). 도약 궤도를 읽고 회피                     |
| **고블린 왕 · Stage2** | 1000   | 걷기 (이속 4)            | Summon(소환) + **돌진 콤보**: 직선 경로 예고 → 26m/s 돌진 → 착지 360° 슬램(반경 8). HP 50% 이하 2연속 돌진 |
| **본 로드 · Stage3**  | 1000   | 걷기 (이속 4)            | **패턴 6종 로테이션** (공격 간격 0.6초): GroundSlam · AreaBarrage(원 4개) · Summon · 십자 충격파 · 점멸 강타 · 추적 장판 |

**v1.4 보스 전투 리워크 요점:**

  - **고블린 왕 돌진 리워크**: 돌진 경로 전체에 직사각형 빨간 예고가 깔리고(실제 도달 거리와 정확히 일치), 돌진 후
    착지 지점에 보스보다 큰 360° 슬램(반경 8m, 예고 0.75초)이 이어진다. HP 50% 이하에서는 짧은
    재조준(0.45초) 후 한 번 더 돌진하는 2연속 패턴으로 강화된다.

  - **본 로드 신규 패턴 3종** (기존 3종과 모양·압박 방식이 겹치지 않게 설계):

|              |                                                          |                |
| ------------ | -------------------------------------------------------- | -------------- |
| **신규 패턴**    | **동작**                                                   | **응징하는 플레이**   |
| **십자 충격파**   | 보스 중심 4방향 직선 예고(길이 18m·폭 4m, 매번 각도 랜덤) → 1.2초 후 동시 타격    | 한 자리 고정        |
| **점멸 강타**    | 플레이어 위치에 원형 예고(반경 7m) → 0.9초 후 보스가 순간이동하며 강타              | 원거리 카이팅        |
| **추적 장판**    | 플레이어를 1.4초 쫓아오는 장판(이속 4.5, 플레이어보다 느림) → 잠금 0.35초 후 폭발     | 제자리 딜          |

  - **충돌 판정 정합**: 보스 명중·접촉 판정 반경을 보스 콜라이더 실측 크기에 맞춰 보정했다(고블린 4m / 스켈레톤
    5.5m). 덩치 큰 보스의 몸통이 판정 반경 밖으로 플레이어를 밀어내 데미지가 안 들어가던 문제의 구조적 해결.

  - **피격 경직 제거**: 걷는 보스(고블린·본 로드)는 피격 Hit 애니메이션을 재생하지 않는다. 자동무기 연타에 보스가
    경직으로 무력화되는 문제를 막아 보스전 긴장감을 유지한다(피격 번쩍임 피드백은 유지).

## 8.3 보스 공격 구조 — 텔레그래프 → 임팩트

모든 보스 AOE는 공통 구조를 따른다: 예고(텔레그래프) → windup → 타격(임팩트). 이 구조가 디자인 기둥 ④(위협
가독성)를 구현한다.

  - **BossAttackBase**: 텔레그래프→임팩트 흐름. SnapToGround로 멀티레벨 지형의 바닥에 정확히 표식을
    붙인다. **windup 도중 보스가 죽으면 데미지를 적용하지 않는다** — 보스 막타 직후 사후 피격으로 죽는 억울한
    상황을 차단(v1.4).

  - **BossAttackOrchestrator**: 초기 지연 후 시작, 공격 간 간격을 두고 라운드로빈 순환(간격은 보스별
    조정 — 본 로드 0.6초) — 예측 가능하되 단조롭지 않게 한다.

  - **TelegraphIndicator**: 빨간 펄스 **원형** 예고 + **직사각형 경로** 예고(SetupRect,
    v1.4 신규 — 돌진·직선 공격용). ImpactBurst로 타격 순간을 강조.

  - **공격 풀**: GroundSlam(단일 원) · AreaBarrage(빨간 원 4개) · Summon(졸개 4마리,
    반경 4m) · Charge(경로 예고 → 26m/s · 0.55초 돌진 → 360° 슬램, 저체력 2연속) ·
    CrossSlash(십자 직선 4방향) · TeleportStrike(점멸 강타) · ChasingZone(추적 장판).

## 8.4 보스 연출

보스 등장·처치 시 배너(BossBanner)가 뜨고, 상단에 보스 전용 HP바(BossHpBarUI)가 표시된다. 보스는 스폰
전 프리워밍(프레임드롭 방지)으로 미리 준비된다. 처치 시 골드 200이 즉시 지급되고 **이속 아이템 1개가 확정
드롭**된다(10.2 참조).

# 9. 스테이지 & 웨이브 구조

## 9.1 웨이브 시스템

WaveSpawner가 시간 기반 5웨이브를 운영한다. 웨이브가 진행될수록 스폰 간격이 짧아지고 적 HP·속도가 상승하며, 지정
웨이브 종료 후 보스가 스폰된다.

|           |                                                     |
| --------- | --------------------------------------------------- |
| **요소**    | **내용**                                              |
| **웨이브 수** | 스테이지당 5웨이브 (시간 기반)                                  |
| **난도 상승** | 스폰 간격 2.0s → 0.8s, 적 HP ×1.0 → ×2.2, 속도 ×1.0 → ×1.5 |
| **스폰 영역** | StageSpawnArea(원형/사각) — 맵 안쪽·바닥으로 보정 클램프            |
| **보스 스폰** | 기본 wave1 종료 후 등장 (맵별 config 조정, 프리워밍으로 프레임드롭 방지)    |

## 9.2 봉인 인카운터 (Arena Encounter)

특정 홀에 진입하면 봉인벽이 활성화되고 웨이브가 시작된다(ArenaEncounterTrigger). 진입 판정은
CharacterController 트리거의 불안정성을 피하기 위해 위치 폴링 방식을 쓴다. 보스를 처치해야 봉인이 풀린다.

## 9.3 Stage3 — 2단 보스 아레나

Stage3는 한 씬에서 보스를 두 번 상대하는 특수 구조다(ArenaPhaseManager + MAP3_v2).

|         |                                                    |
| ------- | -------------------------------------------------- |
| **페이즈** | **전개**                                             |
| 보스 1    | 중앙홀 봉인 → 보스1 처치                                    |
| 전환      | 상층 봉인 개방 → 위층 이동                                   |
| 보스 2    | 강화된 보스2 처치 → 최종 게이트 개방 (_isFinalStage=true → Win) |

*기술 포인트: 단일 WaveSpawner를 재무장(BeginEncounter 오버로드)해 한 씬에서 보스를 2회 운용한다. 거대
벽 메시는 MeshCollider 금지 → 저폴리 Cube/Stairs 프록시 + Environment 레이어로 카메라 충돌을
처리한다.*

## 9.4 스테이지 게이트 & 3스테이지 진행 체인

클리어 시 게이트(StageGate)에 빛기둥이 솟고 미니맵 화살표가 유도한다. 통과하면 다음 맵으로 전환되거나 최종
승리(Win) 처리된다. 진행 체인은 검증 완료되었다.

|          |             |                                                    |
| -------- | ----------- | -------------------------------------------------- |
| **스테이지** | **보스 종족**   | **구조**                                             |
| Stage 1  | 슬라임 (슬라임 킹) | 표준 구조: PlayerSpawn + 스폰영역 + 게이트. 보스 사망 시 게이트 자동 개방 |
| Stage 2  | 고블린 (고블린 킹) | Stage1과 동일 구조 (통합 검증 완료)                           |
| Stage 3  | 스켈레톤 (본 로드) | 봉인 + 2단 보스 특수 구조. ArenaPhaseManager가 게이트 개방 → Win  |

**체인:** Stage1(슬라임) → Stage2(고블린) → Stage3(스켈레톤) → Win. 게이트 인덱스 연결 모두 정상
확인.

## 9.5 난이도 배율

맵별로 적 HP·데미지·보상 배율을 StageDifficulty가 관리한다 (EnemyHp / EnemyDamage /
Reward, 기본 배율 1.0, 맵별 config). 보스 HP는 1000이며, 맵별 데미지 배율(예: ×1.1 등)은
config 예시값이다. 수치 튜닝은 플레이테스트로 계속 조정한다.

# 12. 메타 시스템 (저장 · 랭킹 · 해금 · 온라인)

## 12.1 런 통계 & 누적 점수

런 종료 시 RunStats가 처치·생존시간·골드·레벨을 스냅샷한다. 게이트 통과 시마다 RunTotals가 그 스테이지
스냅샷을 누적하며, 3스테이지를 합산해 최종 누적 점수를 산출한다. **점수 누적은 스테이지 게이트를 통과하는 연속 진행에서만
일어난다** — 게이트 없는 단독 스테이지 플레이는 점수에 합산되지 않는다(의도).

## 12.2 누적 점수 공식

|          |         |
| -------- | ------- |
| **요소**   | **가중치** |
| 골드       | × 1     |
| 처치 수     | × 10    |
| 최고 레벨    | × 100   |
| 클리어 스테이지 | × 1000  |
| **빠른 클리어 보너스** | × 1 |

**누적 점수 = 골드×1 + 처치×10 + 최고레벨×100 + 스테이지×1000 + 빠른 클리어 보너스.**

**빠른 클리어 보너스(v1.4)** = max(0, 클리어 스테이지 × 300초 − 누적 클리어 시간) × 1. 스테이지당
기준시간 5분(300초)에서 실제로 아낀 초만큼 점수가 된다 — **빨리 깰수록 점수가 오르고**, 기준보다 느려도 감점은
없다. (v1.3까지는 생존 시간이 길수록 점수가 오르는 가산 방식이었으나, '몬스터를 많이·빨리·높은 레벨로·부유하게'라는
점수 철학에 맞춰 시간 항목의 방향을 반전했다. 스테이지 진행이 여전히 가장 큰 가중치를 가져 '완주'를 강하게 보상한다.)

## 12.3 스테이지 해금

처음에는 Stage1만 열려 있고(StageProgress, PlayerPrefs), 클리어 시 다음 스테이지가 해금된다. 진행은
PC 로컬에 저장된다.

## 12.4 온라인 리더보드

OnlineLeaderboard가 Firebase Realtime DB에 REST(UnityWebRequest)로 직접 통신한다
— 외부 패키지 0개. 닉네임(3글자) + 누적 점수를 등록하고 상위 10위를 표시한다. 로컬 BEST(PlayerPrefs)
갱신 시 '신기록\!'을 띄운다.

*알려진 한계: 공개 쓰기 규칙이라 치팅이 가능하다 — 캐주얼 랭킹으로 감수하되, 추후 서버 검증을 로드맵에 둔다.*

## 12.5 옵션 영속

SettingsService가 옵션을 PlayerPrefs에 저장한다: 마우스 감도(기본 0.15), Master / BGM /
SFX / UI 볼륨(각 기본 0.8). 해금·BEST·닉네임·옵션 모두 PC 로컬(PlayerPrefs/레지스트리)에 유지되며,
다른 PC와는 동기화되지 않는다.

# 16. 세계관 & 스토리

## 16.1 세계 설정

1400년대 중세 유럽풍의 시골 마을이 무대다. 500년 전 인류는 마물과의 전쟁에서 승리하고 그들을 봉인했지만, 세월이 흘러
봉인의 균열이 벌어지면서 잊혀졌던 마물들이 다시 인간을 공격하기 시작한다.

## 16.2 메인 스토리

주인공은 마을에 남은 유일한 용사이자 마지막 수호자다. 과거 용사들의 흔적을 따라 여행하며 봉인의 진실과 마물이 다시 나타난
이유를 파헤친다. 성으로 향하는 여정은 세 무대를 거치며, 각 스테이지의 보스를 처치하는 것이 메인 퀘스트다.

|             |        |                          |
| ----------- | ------ | ------------------------ |
| **스테이지**    | **무대** | **대표 적 — 보스**            |
| **Stage 1** | 마을과 숲  | 슬라임 — 슬라임 왕(SLIME KING)  |
| **Stage 2** | 성벽 앞   | 고블린 — 고블린 왕(GOBLIN KING) |
| **Stage 3** | 성 내부   | 스켈레톤 — 본 로드(BONE LORD)   |

*코드 정합: 적·보스 매핑은 구현 기준(S1 슬라임 → S2 고블린 → S3 스켈레톤)으로 정리했다. 초기 기획의 '성벽 앞·성
내부' 서사를 이 순서에 대응시켰다.*

## 16.3 톤 & 무드

'장송의 프리렌'처럼 잔잔하고 감성적인 정서를 기반에 깔되, 그 위에 발랄하고 귀여우며 밝은 무드를 강조한다. 3D와 도트
일러스트를 혼합해 아기자기한 매력을 살리고, 끝없이 몰려오는 마물과 죽음의 무한 회귀라는 잔혹한 설정을 경쾌한
톤으로 감싸 '파워 트립(Power Trip)'의 쾌감을 부각한다.

# 17. 아트 디렉션

## 17.1 비주얼 콘셉트

3D 모델링과 픽셀 아트(도트 일러스트)를 결합한 혼합 스타일을 지향한다. 완성되다 만 듯한 러프한 그림체를 의도적으로 살려
아기자기하고 친근한 인상을 준다.

## 17.2 캐릭터 & 몬스터 가이드

**비율·색감:** 4등신 이하의 SD/MD 비율로 디자인하고, 원색과 파스텔톤을 주로 사용한다.

**주인공:** 짧은 은회색 단발에 큰 금빛 눈을 가진 작은 체구의 소녀. 검은 망토와 후드, 낡은 가죽 장비, 벨트 파우치,
부츠로 모험가 느낌을 주며 차분한 회색·검정 계열 색감을 쓴다.

*직업 표현(코드 정합): 인게임은 3직업(전사=검 / 거너=총 / 마법사=마법)으로 분기하며, 캐릭터 선택 화면은 2D
Spine 프리뷰 3종으로 직업을 전환한다(14장 기술 아키텍처 참조).*

## 17.3 환경 & 오브젝트

숲·마을·성 내부 배경에 나무, 돌, 집, 성벽 등의 지물을 배치한다. 무기와 패시브 아이콘은 픽셀 아트로, 전투 이펙트는 판타지
느낌의 화려한 효과로 표현해 도트·3D, 정적 오브젝트·화려한 이펙트의 대비를 만든다.

## 17.4 애니메이션 방향

대기(스탠딩)와 이동 모션을 중심으로 제작한다. 자동 공격이 빠른 템포로 쏟아지는 특성상 캐릭터의 개별 공격 모션보다 타격
이펙트에 자원을 집중해, 적은 모션으로도 풍부한 전투감을 낸다. (같은 맥락에서 보스의 피격 경직 애니도 비활성 — 8.2 참조.)
